A token launch radar: it ranks 214 pre-token protocols by an implied value derived only from the snapshot's own figures — each category's market-cap/TVL multiple is the median of its tokenised peers, shrunk toward the market median, then adjusted for 7-day TVL momentum, track record since listing, and chain breadth. The dashboard is a hand-built, fully offline radar console with a sortable and filterable board, a per-protocol detail view showing the model's arithmetic, and a concrete six-step farm plan for every row.

## Run it

```sh
node main.ts
```

(with the competition snapshot mounted at /input/snapshot.json and outputs written to /output)
